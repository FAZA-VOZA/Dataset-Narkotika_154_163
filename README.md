# Dataset-Narkotika_154_163

## 📌 Deskripsi Proyek

Repository ini dibuat untuk memenuhi **Tugas 2 Mata Kuliah Temu Kembali Informasi (TKI)**. Dataset berisi **50 dokumen putusan pengadilan** terkait **Pidana Khusus — Narkotika dan Psikotropika** yang diputus di **Pengadilan Negeri Kepanjen** pada rentang tahun **2023–2025** (dan sebagian diputus tahun 2026).

Seluruh dokumen diunduh secara **manual** dari situs resmi **Direktori Putusan Mahkamah Agung Republik Indonesia**. Data bersifat terbuka dan tidak terikat Hak atas Kekayaan Intelektual (HaKI).
